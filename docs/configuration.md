# リマップの設定

Orbit のリマップは、本家 HID Remapper のコアがそのまま行います。設定も、本家の Web 設定ツールでそのまま行えます。

## 設定ツールを開く

1. Orbit を PC につなぎます。
2. Chrome か Chrome 系のブラウザで https://www.remapper.org/config/ を開きます（WebHID を使うため、ほかのブラウザでは動きません）。
3. 「Open device」を押し、「HID Remapper Bluetooth」を選びます。
4. 設定を変えたら、「Save to device」で本体に保存します。保存した設定は、電源を切っても残ります。

設定ツールの使い方は、本家の説明書 https://www.remapper.org/manual/ にあります。式（Expressions）の書き方は、本家の [EXPRESSIONS.md](../firmware/hid-remapper/EXPRESSIONS.md) にあります。

## 機器ごとに設定を分ける

本家の設定ツールでは、入力を選ぶ画面（Select input）の上にある **Port** で、どの機器からの入力かを選べます。

- `all`：すべての機器
- `1`〜`8`：その番号の機器だけ

この番号は、Orbit の画面のカードに出る `P1`、`P2` などのポート番号と同じです（[ポート番号](using.md#ポート番号)）。たとえば、トラックボールが `P1`、キーボードが `P3` なら、Port を `1` にした設定はトラックボールにだけ効きます。

**本家の設定ツールで選べるのは 1〜8 までです。** Orbit は 15 番まで番号を付けますが、9〜15 の機器だけに効く設定は、本家の設定ツールでは作れません。機器ごとに設定を分けたい機器は、1〜8 に収めてください。番号は空いている一番小さいものから付くので、登録が 8 台までなら 1〜8 に収まります。使わない機器を消すと、その番号が空きます。

## まだできないこと

- **機器ごとのレイヤー**：レイヤーは本体に 1 つで、どの機器から切り替えても全部の機器に効きます（本家と同じ）。機器ごとに分ける機能は予定しています。
- **機器が切れたときの解除**：キーを押したまま機器が切れると、押したままに見えることがあります（未確認）。解除の機能は予定しています。
- **キーボードの LED**：Caps Lock などの LED の状態は、機器に送り返しません。
- **Orbit 独自の設定画面**：画面に出す名前を付ける、登録を整理する、などは、今はログの COM ポートの命令でだけできます（[PC からの操作](using.md#pc-からの操作上級者向け)）。
