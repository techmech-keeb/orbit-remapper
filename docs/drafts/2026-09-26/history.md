# 検討経緯と判断理由

初期からE1までの詳細は当時のClaude引き継ぎ原文に記録されています。原文は非公開の原本として、private の `techmech-keeb/keyboard-hardware` の `products/orbit-remapper/archive/2026-09-26/originals/remapper_claude_handoff.md` に保存しています（[成果物一覧](artifacts.md)）。以下は後続の検討を含む索引です。個々の出来事に、記録のない正確な日時は付与していません。

ガンサイトは発想の例で、後のE1採用を無視して必ず銃器風へ戻す条件ではありません。E1採用も、枠と本体の連続性への要求を取り消していません。

## E1での重要な修正

- Glass2を幅53 mm・下部高さ14 mmとした旧包絡を撤回。機械図の幅42 mmなどを用いるモデルへ修正。ただし公式寸法表との整合は未解決。
- 画面を後方Y=12 mm、Z=17 mm、机面から65°へ配置し、透明窓の見通しを調整。
- 下部を覆うサドル、背面ホルダーのスカート、側面プラグ周辺の膨らみを追加。
- ホルダー足・固定位置を変更し、Grove配線を曲がった通路包絡で表現。
- STLのゼロ面積三角形を除去。公称CADの限定された干渉検査とSTL閉鎖性を記録。

## 見送り理由を捏造しない

E2やA〜Fの各案について、記録のない「高コスト」「強度不足」「製造不可能」を理由として追加しません。M5Dial案の採用（2026-09-26）は、R02 の取り下げと構成の変更によるもので、E1 の外観の評価が下がったことを意味しません。元画像を復元できない比較案は、文章記録があることと画像そのものがあることを区別します。
