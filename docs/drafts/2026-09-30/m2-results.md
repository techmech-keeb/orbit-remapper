## 4. 途中で分かったこと（次の人向け）

| 事実 | 対応 |
| --- | --- |
| 本家の設定ツールの命令番号は `int8_t` の enum（`types.h`）。0x80 以上は負の値として本家の switch に落ちるが、Orbit 側で先に横取りするので本家には届かない | `usb.cc` で `tool.cc` を先に通す |
| 新しくペアリングした機器の記述子は、名前を読み終えて引き継ぎを決めるまで本家コアに渡せない（ポート番号が変わりうる） | 新しい行のときだけ保留する。登録済みの機器は今までどおりすぐ渡す |
