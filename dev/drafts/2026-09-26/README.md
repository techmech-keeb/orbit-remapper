## 記録の確度

| 表記 | 意味 |
| --- | --- |
| ユーザー明示 | 会話でユーザーが指定・採用した事項。製造承認等へ拡張しない。 |
| 受諾前提 | 設計側の仮定に対する包括的な了承。個別比較の記録ではない。 |
| 設計判断 | 寸法・構造など、成果物作成時に置いた条件。現物による確定とは異なる。 |
| 提案・分岐 | 検討したが採用が明示されていない案。 |
| 未検証 | 実機動作・製造・寸法整合などの確認が未完了。 |
| 旧仮定・見送り | 過去の記録。現行の指示として再利用しない。 |
